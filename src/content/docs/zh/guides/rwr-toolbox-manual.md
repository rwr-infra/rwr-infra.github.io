# RWR Toolbox 使用手册

本文档介绍 RWR Toolbox 桌面端工具箱的完整使用方法。工具箱面向 Running With Rifles 玩家与模组作者，提供服务器浏览、本地数据检索、模组安装归档、快捷键管理等功能。

## 快速开始

### 首次启动

首次打开应用后，建议先进入 **Settings（设置）** 完成以下基础配置：

1. **Language（语言）**：在设置页面顶部切换界面语言。
2. **Game Path（游戏路径）**：选择你的 RWR 游戏安装目录。路径验证通过后，Dashboard 与 Mod 功能才能正常工作。
3. **Scan Directories（扫描目录）**：添加包含 `media/packages` 的目录（如 Steam 创意工坊目录），用于加载本地武器、物品、载具等数据。

### 路径选择提示

- **Windows**：游戏目录通常为 `C:\Program Files (x86)\Steam\steamapps\common\RunningWithRifles`。
- **macOS**：Steam 安装可能将资源放在 `RunningWithRifles.app/Contents/Resources` 内，工具箱会自动识别常见布局。
- 设置中的 **Validate** 按钮可实时验证目录有效性并统计包数量。

## Dashboard（仪表盘）

Dashboard 是应用的默认首页，提供以下信息：

- **游戏路径状态**：若未配置，会提示前往设置。
- **扫描目录概览**：显示已添加的扫描目录数量与有效包总数。
- **模组归档统计**：显示已归档的模组数量（需开启归档功能）。

---

## Servers（服务器列表）

服务器列表页用于浏览 Running With Rifles 的在线服务器。支持以下操作：

### 浏览与搜索

- 列表默认展示服务器名称、地图、当前/最大人数、游戏模式、版本、地区与延迟。
- 顶部搜索栏支持按名称、地图、模式、版本等关键词实时过滤。
- 点击列表标题栏可切换排序字段（如按延迟、人数排序）。

### 收藏与筛选

- 每行右侧星形按钮可将服务器加入收藏。收藏的服务器可通过筛选器单独查看。
- 支持按地区、游戏模式、版本等维度组合筛选。

### 延迟测试

- 应用默认启用 Ping 测试（可在 Settings 中关闭或调整超时时间）。
- 延迟列会显示每个服务器的网络往返时间，未响应则显示超时状态。

### 分页与刷新

- 列表底部提供分页控件，支持调整每页显示数量。
- 刷新按钮可重新拉取最新服务器列表。

## Players（玩家查询）

玩家查询页支持检索游戏内玩家的公开数据：

- **搜索**：输入玩家名称进行模糊搜索。
- **结果列表**：展示玩家名称、所属阵营、击杀/死亡、得分等统计信息。
- **排序与分页**：支持按各列排序，分页控件位于列表底部。

---

## Data（数据管理）

数据管理分为 **Local Data（本地数据）** 和 **Hotkeys（快捷键）** 两个主要板块。

### Local Data（本地数据浏览）

在 Settings 中配置扫描目录后，Local Data 页面会加载并索引所有武器、物品、载具、护甲、音频、特效等游戏资源。

#### 浏览模式

- **Grid View（网格视图）**：以卡片形式展示每个资源的缩略图与名称。
- **List View（列表视图）**：以表格形式展示，适合快速对比数值属性。

#### 筛选与搜索

- 左侧/顶部提供分类筛选器（Weapons、Items、Vehicles、Armors 等）。
- 搜索栏支持按名称、内部 ID 过滤。
- 支持按稀有度、类型、阵营等标签进一步筛选。

#### 详情面板

点击任意资源卡片或列表行后，右侧/弹窗会打开详情面板：

- **武器详情**：展示伤害、射程、射速、弹匣、精度等参数；支持查看武器纹理预览。
- **物品详情**：展示价格、重量、效果描述等。
- **载具详情**：展示生命值、速度、载客量、武器挂载等。

#### 快捷操作

- 详情面板内提供 **Open in Editor** 按钮，可直接打开原始 XML 配置文件进行编辑（需系统中存在关联编辑器）。

### Hotkeys（快捷键管理）

快捷键管理页允许浏览、编辑与导入导出游戏按键配置。

#### 浏览配置

- 加载游戏安装目录下的 `hotkeys.xml`，以列表形式展示所有按键绑定。
- 每行显示动作名称、按键、修饰键（Ctrl/Shift/Alt）。

#### 编辑与保存

- 点击编辑按钮可修改指定动作的按键绑定。
- 修改完成后点击保存，应用会将新配置写回 `hotkeys.xml`。

#### 导入/导出

- **Export**：将当前按键配置导出为独立文件，方便备份或在不同设备间迁移。
- **Import**：选择已有的按键配置文件，覆盖当前配置。

## Mods（本地模组）

Mods 页面是模组管理的核心入口，包含 **Install（安装）**、**Bundle（打包）** 和 **Assets（归档）** 三个标签页。

### Install（安装模组）

安装流程采用三步向导设计：

#### Step 1：选择模组包

- 点击 **Select Mod File** 按钮，在文件对话框中选择 `.zip` 格式的 RWRMI 模组包。
- 仅支持通过本工具打包的 RWRMI 格式，典型文件名为 `[RWRMI][game_version]title vversion.zip`。

#### Step 2：查看模组信息

- 选中文件后，工具箱会自动解析压缩包内的 `config.json`，展示模组标题、描述、版本、适配游戏版本、作者等信息。
- 此步骤提供三个辅助按钮：
  - **File List**：打开文件选择弹窗，查看并勾选需要安装的文件。
  - **README**：查看模组作者提供的说明文档。
  - **CHANGELOG**：查看版本更新日志。

#### 文件选择（File List）

文件列表弹窗允许在安装前精确控制哪些文件会被写入游戏目录：

- **默认行为**：首次打开时，`.txt` 文件默认**不勾选**，其余文件默认**全部勾选**。
- **全选 / 反选**：弹窗顶部提供快速操作按钮。
- **单文件切换**：点击行或复选框均可切换勾选状态。
- **预计大小**：弹窗底部实时统计已勾选文件的总大小，便于评估磁盘占用。

#### Step 3：安装选项与执行

- **Target Path**：显示当前游戏安装目录，确认无误后继续。
- **Backup original files**：勾选后会在安装前自动备份即将被覆盖的游戏原文件（仅保留最近一次备份）。
- **Overwrite existing files**：勾选后允许覆盖已存在的同名文件。
- **已选文件摘要**：安装页顶部会再次显示已选文件数量与预计安装大小，确认后点击 **Install** 执行。

安装成功后，若已开启 **Mod Archive（模组归档）**，安装包会自动复制到归档目录。

### Bundle（打包模组）

打包功能用于将本地模组文件夹封装为标准 RWRMI 格式，方便分发。

#### 打包流程

1. 点击 **Select Folder** 选择模组根目录。
2. 工具箱会检查目录内是否存在 `config.json`、README 与 CHANGELOG；若缺失则会自动生成默认模板。
3. 打包完成后会在同级目录输出 `[RWRMI][game_version]title vversion.zip` 文件。

### Assets（模组归档）

Assets 标签页用于管理历史上安装成功的模组压缩包副本。需要先在 Settings 中开启归档功能并指定目录。

#### 开启归档

进入 **Settings → Mod Archive**：

1. 打开 **Enable archive** 开关。
2. 点击 **Select Directory** 选择一个目录用于存放归档的 `.zip` 文件。
3. 此后每次成功安装模组，安装包都会自动复制到该目录（通过 MD5 去重，相同内容的文件不会重复保存）。

#### 归档列表

- 列表展示每个归档模组的标题、版本、适配游戏版本、作者等元数据。
- 点击行可查看详情（完整信息 + 文件列表）。
- **Refresh**：重新扫描归档目录并刷新列表。

#### 重新安装

- 每行右侧的下载图标可将对应归档包带入 **Install** 向导的 Step 2，让用户像全新安装一样再次确认文件选择与安装选项。

#### 删除归档

- 每行右侧的删除图标支持删除归档文件（二次确认弹窗）。注意：删除仅影响归档副本，不会影响已安装到游戏中的文件。

## Settings（设置）

设置页面分为多个板块，全部配置会持久化保存。

### Language & Theme

- **Language**：切换界面显示语言（运行时切换，无需重启）。
- **Theme**：切换浅色 / 深色 / 自动（跟随系统）。

### Steam Launch（Steam 启动配置）

用于配置通过 Steam 启动 RWR 时的命令行参数。

#### 布尔参数

提供常见启动参数的开关，例如：

- `skip_nat_server_usage`
- `debugmode`
- `verbose`
- `opengl`
- `big_water`

#### 键值参数

支持添加自定义键值对（如 `server 192.168.1.1`）。

#### 自定义 Token

文本区域支持按行输入任意额外参数。

#### 启动与复制

- **Copy Args**：将当前完整启动参数文本复制到剪贴板。
- **Launch**：尝试通过 Steam 协议直接启动游戏（需 Steam 客户端运行中）。

### Game Path（游戏路径）

- 选择 RWR 游戏安装目录。选择后建议点击 **Validate** 验证目录有效性。
- 验证通过会显示目录中包含的包（packages）数量。

### Directory Management（扫描目录管理）

- **Add Directory**：添加额外的 `media/packages` 扫描目录（适用于 Steam 创意工坊目录、自定义资源目录）。
- 每行显示目录路径、验证状态、包数量与上次扫描时间。
- 支持启用/停用单个目录、重新验证、删除。

### Mod Archive（模组归档）

- **Enable archive**：开启后，每次成功安装模组会自动保留压缩包副本。
- **Archive Directory**：指定归档存放目录。清除后归档功能暂停，直到重新选择目录。

## 常见问题

### 游戏路径验证失败

- 确认选择的是游戏根目录（包含 `media/packages` 或 `RunningWithRifles.app` 的目录）。
- macOS 用户若通过 Steam 安装，尝试选择 Steam 库中的 `RunningWithRifles` 文件夹，而非 `.app` 本身。

### 模组安装后游戏异常

- 安装前勾选 **Backup original files**，安装后若出现问题，可在 Install 页面 Step 3 点击 **Recover Backup** 恢复原始文件。
- 注意：备份仅保留最近一次，重复备份会覆盖旧备份。

### 归档目录中文件重复

- 工具箱在归档时会对相同文件名进行 MD5 比对。若内容完全相同则跳过复制；若同名但内容不同，则会以时间戳重命名保存两份。

### 安装时提示 "Game path not configured"

- 在 Settings 中正确设置 Game Path 并确保验证通过，且目标路径包含可写入的 `media/packages` 目录。

## 快捷键与提示

- 所有表格支持点击表头排序、底部翻页。
- 弹窗可通过点击背景遮罩或 **Close** 按钮关闭。
- 文件选择弹窗中，行点击与复选框均可切换勾选状态。
- 设置中所有修改均为即时保存，无需手动点击"保存"按钮。
