# RWR QQ Bot

集成 OneBOT API 的 QQ 机器人，用于在 QQ 群中查询服务器状态信息。

## 功能特性

- **服务器状态**: 直接在 QQ 中查询 RWR 服务器状态
- **OneBOT 集成**: 兼容任何 OneBOT 客户端
- **群命令**: 支持 QQ 群命令
