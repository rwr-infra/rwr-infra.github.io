# RWRSG

用于创建玩家交易图片的 Web 界面，方便分享买卖物品的意向。

## 功能特性

- **交易图片生成器**: 创建 visually appealing 的交易图片
- **可分享**: 方便在论坛和社交媒体中分享
- **基于 Web**: 无需安装

## 链接

- **仓库**: [github.com/rwr-infra/rwrsg](https://github.com/rwr-infra/rwrsg)

## 使用场景

- 在社区论坛发布物品出售信息
- 与其他玩家分享求购物品
- 交易截图用于推广
