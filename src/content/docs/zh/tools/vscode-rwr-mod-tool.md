# VSCode RWR Mod Tool

专为增强 RWR 模组开发体验而设计的 VSCode 扩展。

## 功能特性

- **AngelScript 支持**: 在 AngelScript 文件中导航和查找引用
- **代码导航**: 跳转到定义和查找用法
- **XML 验证**: 模组配置的 XML 文件检测和验证
- **模组开发效率**: 专为 RWR 模组作者设计的工具

## 链接

- **仓库**: [github.com/rwr-infra/vscode-rwr-mod-tool](https://github.com/rwr-infra/vscode-rwr-mod-tool)
- **VSCode 市场**: 在 VSCode 扩展中搜索 "RWR Mod Tool"

## 要求

- VSCode 或兼容编辑器（Cursor、VSCodium）
- RWR 模组的 AngelScript 文件
